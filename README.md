# ✨ 박난이 방 공식 댓글 생성기 ✨

박난이 채널([@박난이-d5n](https://www.youtube.com/@%EB%B0%95%EB%82%9C%EC%9D%B4-d5n)) 시청자를 위한 원클릭 리액션/댓글 생성 툴입니다. 

## 🚀 기능 소개

- **총 50개의 커스텀 템플릿 내장**: AI 감성 주접, 채널 밈, 댄스/음악 이모지, 아스키 아트 등 50개의 고품질 텍스트 조합 내장.
- **5개 랜덤 추출 뷰**: 복잡한 카테고리 대신 셔플 한 번으로 5개의 추천 멘트가 등장하며, 직관적으로 고를 수 있습니다.
- **원클릭 클립보드 복사**: 카드를 터치하면 즉시 복사되며, 청각적 피드백(Web Audio 팝 사운드)과 시각적 피드백(토스트 팝업)을 제공합니다.
- **다크 글래스모피즘 테마**: 화려하고 세련된 네온 & 다크 유리 질감 디자인.

## 🛠️ 폴더 구조

```text
park-nani-comment-generator/
├── index.html            # 메인 UI
├── css/
│   └── style.css         # UI 스타일링 (글래스모피즘, 네온 애니메이션)
└── js/
    ├── data.js           # 50개의 템플릿 데이터 소스 (수정/추가 가능)
    ├── clipboard.js      # 클립보드 복사 및 토스트, 사운드 알림 모듈
    └── app.js            # 랜덤 셔플 및 화면 렌더링 로직
```

## 📝 템플릿 데이터 추가/수정 방법

개발자가 아니더라도 쉽게 데이터를 수정할 수 있습니다. `js/data.js` 파일을 열고 아래 형식을 참고해 배열에 텍스트를 추가하세요.

```javascript
{ category: "Template", text: "여기에 새로운 주접 멘트를 입력하세요!" },
```

카테고리는 다음 중 하나를 선택할 수 있습니다 (화면에 예쁜 라벨로 표시됩니다):
- `AI-style`: 길고 감성적인 주접/응원 멘트
- `Template`: 짧고 굵은 밈, 후원 리액션
- `Dance`: 댄스/음악 화력 지원용 이모지
- `ASCII`: 시선 강탈 특수문자 조합

## 🌐 배포 안내

이 프로젝트는 **단일 정적 웹사이트(Static HTML/CSS/JS)**로 제작되어 별도의 서버 세팅이 필요 없습니다.
- **GitHub Pages**: 이 저장소를 GitHub에 올린 뒤 `Settings` > `Pages`에서 `main` 브랜치를 선택하면 즉시 호스팅됩니다.
- **Vercel / Netlify**: 프로젝트 폴더를 연동하면 단 1분 만에 무료 배포가 완료됩니다.
